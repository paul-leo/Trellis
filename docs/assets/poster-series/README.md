# Agent Trellis poster series

Minimal vertical posters (1080x1350) for social posts. Each poster carries the
product name, one pain-point subtitle, a one-line description, and a quiet
install footer; every theme has an English and a Chinese version. The SVG
sources are the editable masters — regenerate PNGs with `qlmanage -t -s 1350`
and center-crop to 1080x1350 with `sips -c 1350 1080`.
