# Trellis v0.15.1

A patch release fixing two CLI gaps found by real-machine smoke testing of
v0.15.0's workspace scope (both were reproducible against a freshly cloned
repo within minutes of first use).

## Fixes

- **`--flag=value` is accepted everywhere** — every CLI flag parser used
  `argv.indexOf("--flag")`, so the GNU-style `=` form was silently dropped:
  `mcp add --args=-y,…` exited 0 with the args never reaching canonical.
  A shared reader (`src/lib/cliArgs.ts`) now backs every parse site
  (`mcp add`/`set`, `mcp scope`/`skill scope`, `mcp-gateway`, `onboard`,
  `migrate`, `skill add`), and `mcp add`/`mcp set` warn on unrecognized
  `--*` tokens so a typo like `--tranport` can't vanish silently either.
- **`mcp remove <name> --workspace`** — workspace MCP entries previously
  had no CLI removal path at all (`mcp remove` only read the global
  `servers.yaml` and reported workspace-only names as "not a canonical MCP
  server"). The new flag deletes the entry from `.agents/config.json` and
  cascades the same sync, so the ownership-ledger-gated propagation removes
  the rendered project-level copies. Removing a shadow only lifts it — the
  global entry survives and takes effect again. The global path's
  not-found message now points at `--workspace` when the name lives in the
  workspace layer.

## Upgrading

```sh
npm i -g agent-trellis@0.15.1
```

No migration needed; both fixes are CLI-surface only and no stored format
changed.
