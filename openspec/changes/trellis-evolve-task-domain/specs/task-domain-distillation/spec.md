# Spec Delta

## Purpose

把用户本地 agent 的真实任务观察蒸馏为可重跑、可判分的考题,并以 per-workspace 题库管理——自我进化任务域的来源、格式与质量线。考题是 harness2 意义上的 benchmark 任务(含锁后台的标准答案),验证永不重放原任务。

## ADDED Requirements

### Requirement: 真实任务观察与蒸馏
系统 SHALL 只读观察用户本地 agent(claude code / codex / pi 等)的真实任务会话,并从中蒸馏**考题六要素**:`task.md`(只描述工作、不描述度量——不得出现评分/标准类词汇)、源材料(保结构去内容)、参考交付物(用户被接受的结果)、rubric(二值判据集,**含过程判据**:少纠错/少报错/不越权类)、副作用声明(重放时必须 mock 的动作)、过程注记(错误点/纠正点/绕路点)。原会话文件 SHALL NOT 被搬动、改写或重放;蒸馏物 SHALL 只含工具调用元数据(白名单字段)与提炼后的文本,**不保留任务原文正文**(保结构去内容)。无明确被接受结果的任务(用户中途放弃)SHALL NOT 产考题,只产观察教训。

#### Scenario: 六要素完备蒸馏
- **WHEN** 一段真实任务会话以被接受的结果结束并被蒸馏
- **THEN** 产出的考题同时具备 task.md/源材料/参考交付物/rubric/副作用声明/过程注记六要素,task.md 中无任何度量词汇

#### Scenario: 无接受结果不产考题
- **WHEN** 用户中途放弃的任务会话被蒸馏
- **THEN** 不产生考题,只记录观察教训;该会话文件原样保留未被改动

#### Scenario: 载荷不入蒸馏物
- **WHEN** 蒸馏含工具入参/返回内容/邮件正文的会话
- **THEN** 蒸馏物中不存在这些原文内容(保结构去内容),凭据形态经擦除,工具调用只留元数据字段

### Requirement: 考题质检与入库
考题入库 SHALL 过**全自动质检闸**:可重跑性(沙盒内可完成)、rubric 每条二值可判、脱敏扫描(无凭据形态)、禁词扫描(无度量词汇)、副作用声明完备(声明覆盖全部副作用类工具);SHALL NOT 设人工过目环节。不过闸的考题 SHALL 拒绝入库并记录原因;质检本身 SHALL 零花费(不调用付费模型)。

#### Scenario: 合格考题自动入库
- **WHEN** 蒸馏出的考题通过全部自动质检项
- **THEN** 考题自动入库,无需人工审核,入库记录含质检结果

#### Scenario: rubric 不可判拒入库
- **WHEN** 考题 rubric 含无法二值判定的判据(如"写得好")
- **THEN** 考题被拒绝入库,原因记为 rubric 不可判,不进入题库

#### Scenario: 凭据形态拒入库
- **WHEN** 蒸馏物任一字段含凭据形态内容(脱敏扫描未过)
- **THEN** 考题被拒绝入库并记因,凭据内容不出现在任何入库记录中

### Requirement: 题库归属与晋升
考题 SHALL 默认归属其来源 workspace 的题库(该 workspace 的配置优化用该 workspace 的题);同一考题跨 ≥2 个 workspace 复现时 SHALL 自动晋升共享题库,SHALL NOT 需要人工审核;晋升 SHALL 幂等(同一考题不重复晋升)。共享题库的考题被任何 workspace 消费时,其 workspace 事实性前提 SHALL 被重新验证(不把 A 项目的事实当 B 项目的假设)。

#### Scenario: workspace 题服务本 workspace
- **WHEN** 某 workspace 蒸馏出考题且未在其他 workspace 复现
- **THEN** 考题只在该 workspace 的验证轮中被使用

#### Scenario: 跨域复现自动晋升
- **WHEN** 同一考题在第二个 workspace 复现
- **THEN** 考题自动晋升共享题库,无重复晋升记录,原 workspace 归属保留

### Requirement: 蒸馏物防注入与防泄漏
蒸馏物中的任务内容 SHALL 一律按数据对待——内容里出现的指令形态文本 SHALL NOT 被当作指令执行或进入系统提示;rubric 与参考交付物(答案键)SHALL NOT 进入提案与选择阶段的证据面(泄漏绊线:发现即拒绝该证据树)。

#### Scenario: 会话内指令形态文本不被执行
- **WHEN** 真实会话内容包含"忽略之前的指令"类文本并被蒸馏进考题
- **THEN** 该文本仅作为数据存在,验证轮中不产生任何指令效果

#### Scenario: 答案键不进证据面
- **WHEN** 提案或选择阶段的证据组装包含 rubric/参考交付物文件
- **THEN** 证据树被泄漏绊线拒绝,组装失败并报错
